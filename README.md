# auass-redesign

نموذج مقترح لإعادة تصميم موقع **الاتحاد العربي لعلوم الفضاء والفلك** ([auass.com](https://auass.com/)). إعداد: Ameer Hamam.

A redesign concept for the Arab Union for Astronomy and Space Sciences website. Arabic (RTL) first, with a full English version.

- **العرض المباشر:** https://itsak7m.github.io/auass-redesign/
- **المقترح والقرارات:** [BRIEF.md](BRIEF.md)
- **تدقيق الموقع الحالي:** [AUDIT.md](AUDIT.md)

> نموذج للعرض: الصفحات عليها `noindex`، والفورمات ما بتبعث أي بيانات.

## لوحة التحكم (`/admin/`)

لوحة عربية بهوية الاتحاد بتعدّل ملفات `content/` مباشرة على GitHub: الأخبار المحرَّرة، والفعاليات، وسماء الشهر، والمجلس الأعلى، والأرشيف، والصفحات. كل حفظ بيصير commit على `main`، وبعدها workflow اسمه **Build site** بيبني `docs/` وبينشره لحاله خلال دقيقة أو دقيقتين. الصور اللي بتنرفع من اللوحة بتنحفظ في `docs/media/uploads/`.

**الدخول برمز (جاهز هلأ):** افتح `/admin/`، والصق GitHub token إله صلاحية الكتابة على الـ repo (Fine-grained token، صلاحية Contents: Read and write). اللوحة بتشرح الخطوات.

**زر "الدخول بحساب GitHub" (اختياري):** GitHub ما بيعطي رمز الدخول إلا لسيرفر بيعرف سر تطبيق OAuth، فبنحتاج خدمة صغيرة مجانية:
1. GitHub ← Settings ← Developer settings ← OAuth Apps ← New OAuth App. الـ Homepage URL هو رابط الموقع، والـ Authorization callback URL هو `https://<اسم-الخدمة>.<الحساب>.workers.dev/callback`.
2. Cloudflare ← Workers ← Create، والصق `tools/oauth-worker.js` واعمل Deploy. بالإعدادات (Variables) حط `GITHUB_CLIENT_ID`، و`GITHUB_CLIENT_SECRET` كـ secret، و`SITE_ORIGIN` = `https://itsak7m.github.io`.
3. حط رابط الخدمة في `src/admin/config.js` بحقل `oauthUrl`، وابنِ الموقع. الزر بيظهر لحاله.

## الأرشيف المنقول

- الأخبار والمقالات بصفحة `/news/` مع بحث فوري وفلاتر حسب النوع (أخبار الاتحاد، محاضرات وفعاليات، أخبار علمية، مقالات)، وصفحة لكل سنة `/news/<سنة>/`.
- كل منشور قديم إله صفحة `/news/<رقم>/`. صفحة الفعاليات فيها أرشيف المحاضرات والورش حسب السنة، ورابط لصفحة المؤتمرات `/events/conferences/`.
- انحذفت من المنشورات رموز دخول Zoom، والإيميلات الشخصية، وأرقام الهواتف. صفحة المجلس الأعلى بدون إيميلات.
- ملفات PDF والفيديوهات اللي كانت على موقع الاتحاد صارت محفوظة بالموقع نفسه (`docs/media/files/`)، والفيديوهات مضغوطة. المواد اللي إلها حقوق نشر لجهات ثانية ضلّت روابط لمصدرها.
- روابط داخل النصوص: `@media/…` لملف بمجلد `docs/media/`، و`@post:<رقم>` لمنشور بالأرشيف، و`@site:<مسار>` لصفحة بالموقع. البناء بيحوّلها للغة الصفحة.

## النسخة الإنجليزية

- **الأخبار والفعاليات والمقالات:** مترجمة كاملة (العنوان والملخص والنص) بحقل `en` بملف المنشور، وكل صفحة مترجمة فيها رابط للأصل العربي.
- **المواد العلمية:** العنوان والملخص بالإنجليزي، والنص الأصلي بالعربي تحتهم.
- **الصفحات:** كلها إلها `title.en` و`body.en`، إلا صفحة "النظام الشمسي" الطويلة: إلها ملخص إنجليزي بحقل `summary.en` فوق النص العربي.
- المنشورات المكتوبة أصلاً بالإنجليزي (304 منشورات) بتظهر بالنسخة الإنجليزية كما هي.

## الأوامر

```bash
npm run build                    # يبني docs/ من content/ و src/
node tools/check.js [shots-dir]  # يفحص: scroll أفقي، روابط داخلية، صور، أخطاء JS، noindex، سطر التذييل (عينة من الأرشيف)
node tools/check.js --all        # نفس الفحص على كل صفحة بالأرشيف
node tools/before-after-shots.js && npm run build   # يحدّث لقطات صفحة "قبل وبعد"
node tools/moon-preview.js && npm run build         # يحدّث صورة القمر المصغّرة بالرئيسية
```

ما في أي مكتبة لازمة للبناء، بس Node 18 أو أحدث. الفحص بيحتاج Playwright.

## تحديث "سماء الشهر"

بنعدّل `content/sky.json` (الشهر، والأحداث، وأطوار القمر) من جدول الاتحاد الشهري، وبعدين بنشغّل `npm run build`. الحدث الجاي بيتحدد ويتميّز تلقائياً حسب تاريخ اليوم.

## القمر التفاعلي (`/moon/`)

بيانات الفوهات بملف `content/moon.json`، والكود بـ `src/assets/js/moon.js` (three.js بنسخة محلية بمجلد `src/assets/vendor/`). القمر بيستعمل خريطة 2K أو 4K حسب حجم الشاشة، وإذا الجهاز ما بيدعم WebGL بتظهر خريطة مسطحة عليها نفس العلامات.

## مصادر الصور

- صورة الواجهة: سديم القاعدة بعدسة تلسكوب جيمس ويب (NASA, ESA, CSA, STScI).
- خريطة القمر: NASA Goddard، مشروع CGI Moon Kit (بيانات LRO/LROC وLOLA).
- بيانات الفوهات: سجل الاتحاد الفلكي الدولي لأسماء معالم الكواكب (IAU/WGPSN).
- الشعار وصور الأخبار والقيادة والمجلس الأعلى والأرشيف من موقع الاتحاد.
